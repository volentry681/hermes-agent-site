Privacy Policy

Hermes Agent — last updated 12 October 2026

1. Who this policy covers

Hermes Agent is a private automation assistant operated by, and used solely by, the owner of the Google Account that authorises it. There are no other users. It is not offered to the public, and it does not process data belonging to anyone other than the account owner.

2. What Google data it accesses

  • gmail.readonly — read the owner's own messages and labels.
  • gmail.compose — create draft messages. No mail is ever sent by the application.
  • calendar.events — read and edit events on calendars the owner's account can access.
  • calendar.calendarlist.readonly — read the list of calendars the account can access.
  • drive.file — create and manage only those Drive files the application itself created, and no others.

3. How the data is used

Only to carry out requests the owner makes of the assistant: to read and summarise the owner's mail; to prepare draft replies for the owner to review and send themselves; to answer questions about the owner's calendar; to maintain that calendar when asked; and to store files the assistant produces.

4. What is never done with it

  • Not sold, rented, or traded.
  • Not shared with, or transferred to, any third party.
  • Not used for advertising or profiling, or to determine creditworthiness or lending eligibility.
  • Not used to train or improve any machine-learning model.
  • Not read by any person other than the account owner.

5. Storage

The authorisation token is stored as a file on the owner's own machine, readable only by the owner's user account, and is used only by the application. Mail and calendar content is processed to produce the answer the owner asked for and is not copied into any third-party service. No Google user data is transmitted to any server other than Google's own APIs.

6. Deletion and revocation

The owner can revoke the application's access at any time at myaccount.google.com/permissions, which immediately invalidates the stored token. Removing the token file from the owner's machine deletes the stored credential.

7. Limited Use disclosure

Hermes Agent's use and transfer to any other app of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

8. Changes to this policy

If this policy changes, the revision date above is updated. As the application has exactly one user, the owner, any change is made with the owner's knowledge.
