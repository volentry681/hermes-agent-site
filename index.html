Hermes Agent

Personal automation for a single Google Account

Hermes Agent is a private, self-hosted automation assistant. It runs on the account owner's own machine and is used by the account owner only. It is not a public service, it has no other users, and it is not offered to the public.

What it does

  • Gmail — reads the owner's own messages so it can search and summarise them on request, and prepares draft replies for the owner to review. It never sends mail.
  • Google Calendar — reads the owner's calendars and events to answer schedule questions, and creates or updates events when the owner asks it to.
  • Google Drive — creates and manages the files the assistant itself produces. It can only see files it created.

Privacy

What data the application accesses, how it is stored, and how it is used is set out in the privacy policy.
